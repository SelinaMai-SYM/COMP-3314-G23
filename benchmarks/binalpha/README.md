# BinAlpha

Status: `unavailable`

Chang et al., AAAI 2015, state 26 binary handwritten alphabets with 30 images randomly selected per alphabet. They cite no source, give no image size, and give no random seed.

No public file with that exact selection was found on 2026-10-20. Binary Alphadigits (Sam Roweis / Simon Lucas; 36 classes, 39 images each, 20×16) was identified and was not substituted.

`load_dataset` raises `DatasetUnavailable`. See `manifest.yaml`.
