# SLPS references

Hou, Nie, Jiao, Zhang and Wu,
[*Learning a Subspace for Clustering via Pattern Shrinking*](https://doi.org/10.1016/j.ipm.2013.01.004),
Information Processing & Management 49(4):871–883, 2013, is the method
specification. The implementation uses its one-shot pattern shrinkage,
PCA and PsKm construction.

The [package README](../README.md) gives equations, orientation conventions,
APIs and comparison limits. The code operates on arrays and requires no
repository-local publisher PDF. No unrelated similarly named method is
substituted.

See [methods](../../../docs/methods.md) and
[reproducibility](../../../docs/reproducibility.md).
