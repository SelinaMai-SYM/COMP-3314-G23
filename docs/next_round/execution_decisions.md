# Execution decisions and claim boundaries

The approved performance plan supersedes old N1/N2-as-main proposals. The locked protocol and initial source are committed before new label-based evaluation. The later IRLS primal-bound amendment is explicitly documented and retains every cold run; it is not independent held-out validation.

- Stage A covers the five original gamma values with 50 greedy++ trials per point. Historical closest rows are audited on freshly generated, separately identified F/W where old arrays cannot be recovered. New outputs do not impersonate historical arrays.
- Stage B runs all five gammas, each with Oracle correction, equal-mass weakening, three random deletions, and three static length thresholds. The gate uses the best certified Stage-A gamma exactly as declared; conditional success at another gamma does not change it.
- Formal real-data capped search is conditional on that gate. If it does not pass, the 220 C jobs remain `NOT_RUN_MECHANISM_NOT_SUPPORTED`; the 15-configuration fairness comparison and four-benchmark target stay NA. This is an evidence decision, not a claim of budget exhaustion.
- Capped theory, exhaustive five-point state validation and synthetic 2-by-2 experiments execute regardless of the real-data gate. Their conclusions are restricted to those models.
- N1's primary synthetic pilot tests the declared Huber parameters and squared-fidelity control. Activation/MSE changes without ACC/NMI improvement do not promote a full real-data parameter search.
- N2's 80-row geometry prerequisite pilot observes subspace/topology sensitivity and higher projected-heat graph stability. This triggers the previously specified primary t=4/r=128 clustering ablations: original, hard-128, heat and W-only; common gamma=1 and own 2*gamma0; same-feature SC controls. It does not trigger Heat+Huber or post-hoc t/r tuning. N2 changes F and is a secondary candidate, not a substitute for the main same-F extension criterion.
- Corrected image robustness reconstructs the entire pipeline for four fixed conditions per dataset with clean gamma=1. These conditions are descriptive, not independent random perturbations. Fixed-R graph perturbation seeds 200..209 are independent units for the separate geometry pilot. No invalid bootstrap across 50 correlated roundings is used to claim image robustness.
- Full N1 real-data grids, N2 t/r/seed sensitivities, adaptive robustness, external RCC benchmark runs, and formal C search are not silently counted as executed. Source commits/licenses and actual external validation scope are recorded separately.

The locked best-certified-gamma gate remains a historical 0/4 result. The former universal claim that analytic baseline points remain F after edge deletion was incorrect: deletion can destroy force cancellation. Only the measured no-movement cases and a separately verified incident-mass sufficient bound justify that statement for particular configurations; see `../submission_refresh/numerical_repairs.md`. It does not test joint graph/parameter oracle capability. Conditional high-gamma effects remain separate findings; the gate is not changed after inspecting them. A/W pollution counts and mass are distinct. The original diagnostic schema measured both graphs’ edge lengths in F; no native-input A length AUROC is claimed.
