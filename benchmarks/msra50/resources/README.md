# MSRA literature references

The related Chang et al. manuscript
[*Improved Spectral Clustering via Embedded Label Propagation*](https://arxiv.org/abs/1411.6241)
reports an MSRA50 table entry with 1,799 samples, 1,024 features and twelve
classes, citing the Laplacianfaces literature. It is a literature reference,
not an image matrix or proof that an available source has identical pixels.

The external version-1 manuscript has recorded SHA-256
`d3d00b0fa2eeff938d65800a3a7e4d1b08987de73932e9bd04de801e708badb2`.
The explicitly loaded EBSA source is native 16×16 and retains its distinct
identity. See [MSRA versions and preparation](../README.md) and the
[project data guide](../../../docs/data.md).
