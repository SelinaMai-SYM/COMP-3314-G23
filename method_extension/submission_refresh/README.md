# Fixed-graph diagnostics

This package contains label-blind graph utilities and explicitly labelled oracle
interventions used to study the input affinity and the separate shrinkage graph.
G1–G3 remain diagnostic evidence, independent of the three new refinements.

The new method modules are in `method_extension/extension_verification`; their
array-based fit interfaces do not accept true labels. See the registered design
and results documents for objectives, numerical qualification and gates.
