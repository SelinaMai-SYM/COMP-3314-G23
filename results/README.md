# Results

Every numeric cell in `tables/` comes from a directory under `../runs/` listed in `run_index.csv`. Paper percentages appear only with the label "Reported in Chang et al. (2015)". Missing work is "N/A — not reproduced". Trial counts are the number of finished clustering seeds, never inflated to 50.

Figures in `figures/` are PDF/SVG/PNG from those same records. Empty series are omitted.
