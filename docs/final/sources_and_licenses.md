# Source, attribution and code ownership

This is a COMP3314 course project, not a claim to have invented convex clustering, PDHG, Huber fidelity, diffusion clustering or truncated fusion. Mathematical formulas are implemented from scratch in the current Python modules unless explicitly stated below. Baseline reconstruction limitations are preserved in the method registry.

The two historical scientific snapshots have exact source/config/dependency hash manifests under `archive/source/`. They exclude licensed data and restricted full text. No repository-wide license is inferred for a historical version that did not contain one. Current entrypoints never import the snapshots or access old Git objects.

The native prclust five-point output is `results/next_round/prclust_native_small_check.txt`; parameters and results are a software sanity check, not a comparison to SSC E8, whose fidelity differs. It accepts no ground-truth labels for fitting. Native source was obtained at the exact revision above and built in a temporary local R library; it is not a required dependency of the published Python setup.

Data sources and provider conditions are in `data_setup.md` and the external-data manifests. JAFFE images and the private publisher PDF from the user's v2 worktree are not added to Git. Reported paper numbers are attributed separately from our reproduction/adapted settings.
