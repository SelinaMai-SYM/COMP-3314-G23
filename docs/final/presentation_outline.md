The qualification belongs beside each headline result: “Closest evaluated reconstruction; historical subset unverified.” Show both metrics from the same selected configuration, its source/subset ID, sample count, initialization, E8/E13 and nominal/effective gamma, solver status and statistical endpoint. Mean-endpoint SD describes the declared trials; a single native-best assignment receives no across-run SD.

For the subset campaign, distinguish the four contrasts: reference candidate/reference settings; candidates/reference settings; reference candidate/frozen grid; candidates/frozen grid. This keeps a combined source/parameter change from being credited only to sample selection. On a selected candidate, compare SC and SSC using exactly the same saved F and rounding seeds.

Use the actual gate and coverage files when deciding which extension slide is appropriate. If G3 was not evaluated because of the shared allowance, describe it as unrun rather than failed. If certification remained unresolved, identify the numerical limitation. If G3 failed, show that measured result and the preregistered dependent skips. Only a passed G3 gate permits the frozen EnSC adaptation; existing methods and reused code retain their citations. No new Huber, capped-fusion or heat grids belong to this refresh.

Useful Q&A prompts:

- Why can a convexly optimal representation cluster poorly? Separate the fixed-graph objective from upstream representation and nonconvex rounding.
- Why did the closest-to-paper configuration change? Explain the fixed joint minimax criterion, complete seed sets and same-configuration ACC/NMI, then point to the preserved ACC-only selections.
- Does a better numerical match prove the original dataset was recovered? Explain the missing original indices, reproducible candidate manifests and remaining identity uncertainty.
- What does additional rounding establish? It checks new rounding seeds on the same samples and G; it does not establish unseen-data generalization or label-free selection.
- Was the SSC baseline fairly tuned? Show the applicable complete configuration grid and strongest valid controls, rather than relying only on gamma 1.
- Can deleting edges preserve G=F automatically? Use the eight-cycle counterexample and distinguish it from a separately valid incident-mass sufficient bound.
- What failed or remains unrun? Refer to [current coverage](../../results/submission_refresh/execution_coverage.csv), [source recovery](../submission_refresh/source_recovery.md) and the [handover](../submission_refresh/final_handover.md). Keep internal numerical limitations separate from external identity restrictions.

The predeclared two-percentage-point macro-ACC target is a research goal. Present its actual qualification and coverage, including NA where required, rather than treating it as a promised outcome. Earlier synthetic capped-fusion and heat results are historical evidence with their own limitations; they cannot replace a missing real-data confirmation.
