# SSC references

The mathematical specification is Chang, Nie, Ma, Yang and Zhou,
[*A Convex Formulation for Spectral Shrunk Clustering*](https://doi.org/10.1609/aaai.v29i1.9606),
AAAI 2015, pp. 2532–2538. The
[arXiv preprint](https://arxiv.org/abs/1411.6308) is a separate version.

Publisher PDFs are not required as repository-local runtime resources.
This package is a paper-based reconstruction, not recovered author software.
The E8/E13 distinction and explicit numerical assumptions are documented in
the [library README](../README.md),
[methods](../../docs/methods.md) and [theory](../../docs/theory.md).
