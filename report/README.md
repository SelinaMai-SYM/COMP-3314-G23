# COMP3314 course report (NeurIPS 2026 preprint style)

This directory is the written report for HKU COMP3314 Group 23. It uses the official NeurIPS 2026 style with the **preprint** option. It is a course project, not a NeurIPS submission.

## Compile

From this `report/` directory:

```bash
latexmk -pdf -interaction=nonstopmode main.tex
```

Equivalent one-shot sequence if `latexmk` is unavailable:

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

The expected PDFs are `main.pdf` and an identical copy `Group_23.pdf`.

Main text (title through conclusion, including the abstract) must fit in **four pages**. References, appendix, and the NeurIPS checklist are excluded from that cap. Do not edit `neurips_2026.sty` fonts, margins, or spacing to squeeze. After `latexmk`, check with `pdfinfo`, `pdftotext -layout`, and `rg Overfull main.log`.

## Layout

- `main.tex` — body, appendix, and checklist input
- `references.bib` — verified BibTeX entries
- `neurips_2026.sty` — copied from the official NeurIPS 2026 bundle
- `checklist.tex` — NeurIPS checklist with answers that match this PDF
- `tables/` — generated by `scripts/generate_report_tables.py` from `runs/`
- `figures/` — PDF/PNG copied from `results/figures/` by `scripts/generate_report_figures.py`

Do not paste clustering ACC/NMI by hand. Regenerate the table and figure scripts from the `v1` root, then recompile.
