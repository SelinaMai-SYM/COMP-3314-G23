# LDA-Kmeans references

The primary method is Ding and Li,
[*Adaptive Dimension Reduction Using Discriminant Analysis and K-means Clustering*](https://doi.org/10.1145/1273496.1273562),
ICML 2007, pp. 521–528.

The separately observed software reference is
[ClustPy revision 4ac9d00685efc7432800684f5bfac0f01af59172](https://github.com/collinleiber/ClustPy/blob/4ac9d00685efc7432800684f5bfac0f01af59172/clustpy/centroid/ldakmeans.py).
Its original code and [BSD-3-Clause license](../vendor/clustpy/LICENSE)
remain available. Paper-based reconstruction, pinned software behavior and
the ridge adaptation are distinct implementations in the
[package documentation](../README.md).

No local publisher PDF is required for fitting. See
[methods](../../../docs/methods.md) and
[reproducibility](../../../docs/reproducibility.md).
